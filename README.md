# 🚀 Featured Projects

## 🎙️ AI-Powered IELTS Speaking Evaluator

<div align="center">

### Turning spoken answers into structured IELTS evaluation 🤖

</div>

A real-world AI-powered system designed to analyse IELTS Speaking responses
using speech processing, language analysis and LLM-based evaluation.

```text
🎤 User Audio
      │
      ▼
🗣️ Speech-to-Text
      │
      ▼
📝 Transcript + Audio Information
      │
      ▼
📊 Language Analysis
      │
      ├── Grammar
      ├── Vocabulary
      ├── Fluency
      └── Pronunciation
      │
      ▼
🤖 Gemini / GPT
      │
      ▼
📈 IELTS Evaluation
```

### 🔍 Evaluation Areas

| Area                    | What is analysed                                 |
| ----------------------- | ------------------------------------------------ |
| 🗣️ Fluency & Coherence | Flow, pauses, coherence and response structure   |
| 📚 Lexical Resource     | Vocabulary usage and range                       |
| ✍️ Grammar              | Grammar accuracy and grammatical range           |
| 🔊 Pronunciation        | Pitch, timing and pronunciation-related metrics  |
| 🎴 Cue Card             | Response relevance to prompt/image/audio context |
| 💬 Discussion           | Relevance and quality of discussion responses    |

### 🛠️ Stack

`Laravel` `Python` `Faster-Whisper` `LanguageTool` `Gemini` `OpenAI`

# 🔥 Fire & Smoke Detection System

<div align="center">

### 👁️ AI-powered computer vision for safety monitoring

**CCTV → Computer Vision → AI Analysis → Alerts 🚨**

</div>

A computer-vision based system focused on detecting **fire and smoke**
from camera streams and providing useful information for monitoring
and alerting systems.

```text
                 📹 CCTV / IP Cameras
                         │
                         ▼
              ┌─────────────────────┐
              │   Stream Processing  │
              │       OpenCV         │
              └──────────┬──────────┘
                         │
                         ▼
              ┌─────────────────────┐
              │    AI Detection     │
              │       YOLO          │
              │  🔥 Fire / 💨 Smoke │
              └──────────┬──────────┘
                         │
                         ▼
              ┌─────────────────────┐
              │    AI Analysis      │
              │ Severity / Context  │
              └──────────┬──────────┘
                         │
                         ▼
              ┌─────────────────────┐
              │   React Dashboard   │
              │     🚨 Alerts       │
              └─────────────────────┘
```

### 🚨 Core Features

* 🔥 Fire detection
* 💨 Smoke detection
* 🎥 Camera stream processing
* 📡 RTSP / ONVIF / HTTP camera support
* 🧠 AI-based analysis
* 📸 Detection snapshots
* ⏱️ Detection timestamps
* 📍 Camera information
* 🚨 Real-time alerts
* 📊 Monitoring dashboard

### 🛠️ Stack

`Python` `OpenCV` `YOLO` `FastAPI` `React` `TypeScript` `Socket.IO`
